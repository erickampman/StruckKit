# Changelog

All notable changes to StruckKit. Versions follow the git tags; the format is
[Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Changed

- Help opens the help page in a window of the plugin's own, not in the web browser. Nothing is
  written to the temp folder, and on Linux no web server runs in the host any more.

## [0.9.0] - 2026-11-14

First public preview.

### Added

- Physically modelled drum kit in one instance: snare with wires, two-headed toms, crashes, ride and
  hi-hats, plus an octave of hand drums and percussion.
- Controls in physical quantities: cymbal size and thickness, snare wire tension, tom tuning.
- Its own key map, a whole kit on one track.
- CLAP plugin for Linux (x86-64) and macOS 26 or later (Apple Silicon).

- See the README's Known gaps section.
